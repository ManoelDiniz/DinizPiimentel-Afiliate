# Adicione suas imagens de produtos aqui

## Formato recomendado:
- **Formato**: JPG ou WebP
- **Dimensões**: 800x800px ou 1200x1200px
- **Tamanho**: < 200KB por imagem

## Nomenclatura:
- Use nomes descritivos
- Exemplo: `fone-qcy-t13.jpg`
- Exemplo: `mouse-logitech-g203.jpg`
