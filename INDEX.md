## ⚡ Quick Start (Super Rápido)

### 1️⃣ Instalar
```powershell
npm install
```

### 2️⃣ Configurar
Edite estes 4 arquivos com suas informações:
- `app/layout.tsx` (linha 7) → seu domínio
- `app/sitemap.ts` (linha 4) → seu domínio
- `app/robots.ts` (linha 10) → seu domínio
- `components/Analytics.tsx` (linha 8) → seu GA ID

### 3️⃣ Rodar
```powershell
npm run dev
```
Acesse: http://localhost:3000

### 4️⃣ Deploy
```powershell
git init
git add .
git commit -m "initial commit"
git remote add origin [seu-repositorio]
git push -u origin main
```
Depois conecte na Vercel → Auto-deploy!
